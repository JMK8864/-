# 장치A(국번1) · 장치B(국번2) 래더 프로그램 — MELSEC iQ-R / GX Works3

> 대상: 교재 4.2.1 「PLC 프로그램 제어 내용」, 4.2.2 「PLC 프로그램 작성 포인트」
> 구성: iQ-R CPU(R04/R08/R16CPU 등) + CC-Link IE 컨트롤러 네트워크 유닛(RJ71GP21-SX) 2국
> 표기: GX Works3 래더 편집기에 그대로 입력할 수 있는 명령어(니모닉) + 래더 도식

---

## 1. 네트워크 파라미터 (GX Works3)

`내비게이션 → 파라미터 → 유닛 정보 → RJ71GP21-SX` 에서 설정

| 항목 | 장치A (국번1) | 장치B (국번2) |
|---|---|---|
| 네트워크 No. | 1 | 1 |
| 국번 | 1 | 2 |
| 국 종별 | 관리국 | 통상국 |
| 네트워크 범위 할당 (관리국에서만 설정) | 국번1: LB 0000~00FF, LW 0000~00FF<br>국번2: LB 0100~01FF, LW 0100~01FF | (관리국 설정을 수신) |
| 리프레시 설정 | LB 0000~01FF ↔ B 0000~01FF<br>LW 0000~01FF ↔ W 0000~01FF<br>SB 0000~01FF ↔ SB 0000~01FF<br>SW 0000~01FF ↔ SW 0000~01FF | 좌동 |

결과적으로 아래와 같이 공유된다.

| 링크 디바이스 | 송신국 → 수신국 | 의미 |
|---|---|---|
| B0 | A → B | 장치B 운전 준비 지시 |
| B1 | A → B | 장치B 운전 시작 지시 |
| B2 | A → B | 총 생산수 달성 |
| W0 | A → B | 장치B 목표 생산수 지시 |
| B100 | B → A | 장치B 운전 준비 완료 |
| B101 | B → A | 장치B 운전중 |
| W100 | B → A | 장치B 생산수 |

### 사용하는 링크 특수 릴레이/레지스터 (4.2.2 (2))

| 디바이스 | 내용 (CC-Link IE 컨트롤러 네트워크) |
|---|---|
| SB49 | 자국 데이터 링크 상태 (OFF: 정상, ON: 이상) |
| SW74 | 각 국 사이클릭 전송 상태 (bit0 = 국번1, bit1 = 국번2 … / 0: 정상, 1: 이상) |

> 유닛이 CC-Link IE **필드** 네트워크(RJ71GF11-T2)라면 각국 상태는 SW00B0~ 를 사용한다. 사용 유닛 매뉴얼의 SB/SW 일람으로 번호를 꼭 확인할 것.

## 4. 동작 시퀀스 (핸드셰이크)

```
장치A                                         장치B
X0·X3 ON → M0/Y70
X2 ↑     → M10(운전) SET, D0=0
          ── B0 SET ───────────────────────▶  M2 래치
          ◀────────────────── B100 ON ──────  (M2·M0)
B100 확인 → B0 RST
X4 ON    ── B1 SET ───────────────────────▶  D0=0, M10·M12 SET
          ◀────────────────── B101 ON ──────  운전중
B101 확인 → B1 RST, M11 SET
X5 ↑ → D0+1                                   X3 ↑ → D0+1
          ◀────────────────── W100 = D0 ────
D10 = D0 + W100
D10 ≥ D20 → M20 SET, M10 RST
          ── B2 SET ───────────────────────▶  M10 RST, M2 RST
          ◀────────────────── B101 OFF ─────
B101 OFF + 1초 → B2 RST
```

## 5. 작성 포인트 반영 내용

| 교재 항목 | 반영 위치 |
|---|---|
| (1) 네트워크 상태를 인터록 조건에 사용 | A (1)·(6)·(7)·(8), B (0)·(2)·(4)·(7)·(9): SB49·SW74 로 만든 M1 을 송수신 조건에 넣음 |
| (2) SB/SW 사용 | SB49(자국 데이터 링크), SW74.n(상대국 사이클릭 전송 상태) |
| (3)(a) ON/OFF 신호 송수신 | B0·B1·B2 를 OUT 이 아닌 SET/RST 로 송신, 상대국 응답(B100·B101) 확인 후 리셋. B2 는 B101 OFF 확인 + T0 1초로 ON 시간 확보 |
| (3)(b) 32비트 데이터 | 이 예는 16비트(W0, W100)만 사용. 32비트로 바꿀 경우 「32비트 데이터 보증」 조건(선두 짝수 번지 등)을 유닛 매뉴얼로 확인 |
| (3)(c) 복수 워드 | 여러 워드를 한 번에 보낼 때는 파라미터에서 「국 단위 블록 보증」 사용 |

## 6. 주의 사항

- **새 사이클 시작 시 이전 W100 값**: A가 재시작하면 D0 은 0 이지만 W100 에는 B의 이전 생산수가 남아 있어 즉시 「달성」으로 판정될 수 있다. 그래서 A는 B가 새로 운전을 시작(B101 상승)한 뒤에만 W100 을 더한다(M11). B는 운전 시작 스캔에 D0 을 0 으로 지우므로 B101 과 W100=0 이 같은 링크 주기로 전달된다.
- **BCD 출력 범위**: K4Y40/K4Y50 은 BCD 4자리라 0~9999 까지 표시된다. 9999 를 넘으면 BCD 명령이 연산 오류가 되므로 목표 생산수를 9999 이하로 둔다.
- **목표 생산수 D20/D21**: 예시는 SM402(RUN 후 1스캔)로 1000/500 을 넣는다. 실제로는 HMI 에서 써 넣거나 래치(정전 유지) 범위로 둔다.
- **장치B 단독 운전(X2)**: M12=OFF 로 운전하므로 A의 B2 로 정지하지 않고, 통신 이상에도 정지하지 않는다. 정지는 X0(이상)으로만 된다. 목표 W0(D20)에 도달하면 정지시키려면 `LD>= D0 D20` / `ANI M12` / `RST M10` 렁을 추가한다.
- **타이머**: iQ-R 기본 타이머는 100ms 단위이므로 `T0 K10` = 1초.
- **SB/SW 번호**: SB49·SW74 는 CC-Link IE 컨트롤러 네트워크(RJ71GP21-SX) 기준이다. 리프레시 설정에서 SB/SW 를 다른 번지로 옮겼다면 그 번지로 바꾼다.
